## 1. mattpocock/skills

**项目定位**

面向真实工程流程的 Agent Skills 集合。它把 PRD 生成、Issue 拆分、TDD、架构改进、预提交保护、文章编辑等常见工程动作，整理成可以复用的 AI Agent 技能。

**为什么值得关注**

AI 编码正在从“单次提示词”转向“可复用工作流”。这个项目的价值不在于某一个技能本身，而在于把工程团队里反复发生的流程沉淀为稳定模板，让不同成员、不同项目之间的执行质量更一致。

**最佳实践场景**

团队内部建立统一的 AI 编码工作流：需求先转成 PRD，再拆成独立 Issue，开发阶段按 TDD 执行，提交前用 guardrail 阻断危险 Git 操作。适合希望减少提示词差异、提高交付稳定性的研发团队。

## 2. Z4nzu/hackingtool

**项目定位**

安全研究与渗透测试工具聚合器，覆盖信息收集、Web 安全、取证、云安全、移动安全等多个类别，偏向工具导航、安装管理和实验环境组织。

**为什么值得关注**

安全工具生态分散、上手成本高。这个项目用菜单和分类把常见工具组织起来，对安全培训、工具选型和实验室环境搭建有一定参考价值。

**最佳实践场景**

企业安全团队在已授权、隔离的测试环境中做工具选型和攻防演练准备。例如用它快速了解信息收集、漏洞扫描、密钥泄露检测等工具的分类边界，再把真正采用的工具纳入内部标准流程。

> 注意：安全类项目只适合授权测试、教学和防御研究，不应用于未授权目标。

## 3. Alishahryar1/free-claude-code

**项目定位**

Claude Code 的 Anthropic API 兼容代理。它可以把 Claude Code 的请求转发到 NVIDIA NIM、OpenRouter、DeepSeek、LM Studio、llama.cpp、Ollama 等云端或本地模型提供方。

**为什么值得关注**

AI 编码工具的核心体验和模型供应商正在解耦。这个项目关注的是“保留 Claude Code 使用习惯，同时切换不同模型后端”，适合做成本控制、本地模型实验和多模型路由验证。

**最佳实践场景**

个人或团队研发环境中做多模型路由实验：轻量任务走本地 Ollama 或 LM Studio，复杂任务走云端模型，统一保留 Claude Code 的命令行使用方式。正式接入前应重点验证隐私、稳定性、模型能力和授权条款。
