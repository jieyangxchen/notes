# 每日 GitHub TOP3 跟踪

这里记录 GitHub Trending Daily 中“今日新增 Star”最高的 3 个开源项目。

## 跟踪规则

- 数据来源：[GitHub Trending](https://github.com/trending?since=daily)
- 排序方式：按页面中的 `stars today` 数值从高到低排序
- 记录内容：今日总览、今日观察、数据速览、适合/不适合对象、风险、试用方案
- 补充信号：最近提交、Issue/PR 活跃、Release、License、维护主体、README 成熟度、Demo/文档/安装入口、今日新增占总 Star 比例
- 更新频率：每天早上 8 点自动追加，失败后会进行一次延迟重试
