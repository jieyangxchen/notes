**不适合谁关注**

不适合对延迟和稳定性要求严苛的生产系统（如金融高频交易），因免费提供商可用性不可控；不适合处理敏感数据且不愿自托管的合规场景，数据经网关有泄露风险。

**我会怎么试用它**

- 安装：`npx omniroute` 或 Docker `docker run -p 3000:3000 omniroute/omniroute`，设置环境变量指定要聚合的免费模型 key。
- 试跑：选择 3 个常用编码任务，分别通过官方 API 和 OmniRoute 执行，记录延迟、成功率与输出质量。

- 退出：若免费额度频繁耗尽导致服务不可用，或压缩后模型输出严重下降，退回原生 API；若项目停更，迁移至其他网关如 LiteLLM。
