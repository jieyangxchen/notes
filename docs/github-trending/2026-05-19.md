**适合谁关注**

**不适合谁关注**

不适用于无视robots.txt、恶意攻击或大规模商业爬取。用户需自行评估目标站点的服务条款和当地法规，隐身能力可能随网站检测升级而降低。缺乏内置的频率控制，需开发者自行实现。
