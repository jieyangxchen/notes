**项目定位**

面向使用 Cursor、Claude Code、Codex 等编码代理的开发者，解决架构文档难以维护、代码评审缺乏直观视图的问题。它将代码库或系统描述编译为自包含 HTML 图表，支持五类图、四种预设、明暗主题，并提供 Before/Delta/After 快照对比和节点溯源。能力边界：不自动发现运行时拓扑，依赖代理生成的 JSON IR；验证和真相需人工确认；适合静态架构而非实时监控。

**为什么值得关注**

今日新增 4239 星，占比 18.35%，属于新项目爆发；总星 2.3 万。1 天前有提交，最新 release v2.15.0（2026-08-17），README 成熟（15k 字符）且有文档、演示和安装说明。近 30 天 issue 45、PR 62，讨论活跃。开发者可关注其作为 AI 生成图表的标准层，以及快照对比能力是否成为代码评审新范式。

**适合谁关注**

适合使用 AI 编码代理的开发团队，需要在合并前快速理解架构变更；适合架构师用自然语言生成设计图；适合需要把图表嵌入文档或演示的场合。需具备 Node.js 环境和基本 agent skill 配置能力。

**不适合谁关注**

不适合需要实时运行时监控的用户；不适合希望零部署直接使用的非技术成员；若代码库与生成结果偏差大且缺乏人工核对机制，可能引入误导。个人维护项目，企业刚需场景需谨慎评估长期支持。

**风险或争议点**

依赖大模型生成结构化 JSON，可能产生幻觉或漏掉关键依赖；变更对比仅基于输入快照，无法捕获未纳入建模的运行时行为；作为 agent skill，权限边界需遵循宿主工具的安全设置。项目托管在个人账号，长期维护依赖社区，无企业背书。

**最佳实践场景**

在代码评审流程中，每次 PR 触发代理调用 Archify 生成架构 diff，评审者用 Delta 视图快速审查新增、删除、改道节点，并点击节点溯源到源码，提升跨团队沟通效率。

**我会怎么试用它**

- 安装：按 README 将 Archify 配置为 Cursor 或 Claude Code 的 Agent Skill，并安装 Node.js 依赖。

- 退出：若节点错误率高于 30% 或结果不可解释，则停用并回退到现有文档工具。
