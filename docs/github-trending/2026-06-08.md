**项目定位**

今日新进 TOP3，暂无昨日同榜对比

**适合谁关注**

适合在VPS、边缘设备或本地环境构建内存敏感型RAG管道；适合想替换FAISS获得更高吞吐和更低资源消耗的团队；适合已使用LangChain/LlamaIndex/Haystack等框架，期望零改动的向量存储升级。

**不适合谁关注**

不适合需要GPU加速或分布式索引的超大规模集群；不适合依赖FAISS高级索引（如HNSW）且无法迁移的用户；不适合硬件不支持AVX-512或NEON的旧式服务器；新项目生态较小，生产级风险承受低的团队慎用。

**最佳实践场景**
