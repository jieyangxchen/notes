**最佳实践场景**

**我会怎么试用它**

- 试跑：输入一段中文文本，尝试基础合成，然后上传一段5秒参考音频测试声音克隆效果，评估自然度和相似度。
- 评估：计算实时率（RTF）、语音自然度（MOS分）、克隆话音色相似度，统计30种语言的可懂度。
- 退出：若合成质量达不到产品要求（MOS<3.5）或存在无法解决的延迟问题，则考虑结合其他TTS引擎混合方案。
