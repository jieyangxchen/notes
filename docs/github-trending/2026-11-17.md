**最佳实践场景**

**我会怎么试用它**

- 安装：用 pip 或 uv 安装 skillevaluator，先用自带 text-analyzer 示例在无 API Key 下跑出静态质量分，再按需接 NVIDIA Build 或其他模型端点。

- 退出：若评分与实际使用效果长期不相关，或评测成本高于人工评审收益，则保留静态检查而放弃实跑评测。
