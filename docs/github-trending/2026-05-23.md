面向使用 Claude Code、Cursor 等工具的开发者，解决大型代码库 AI 探索时 token 消耗高、响应慢的问题。通过本地知识图谱替代大量 grep/glob，仅加速代码理解，不涉及生成或修改；动态语言与元编程覆盖可能不全，索引需按需重建。

**适合谁关注**

**不适合谁关注**

小型项目或单文件探索，图谱构建开销大于收益；不使用 Claude Code 等支持工具的开发者无法受益；高度动态语言或非标准构建系统可能导致图谱不准确；索引更新需手动触发，高频变更项目需频繁重建。

**最佳实践场景**

接手一个遗留大型前端项目时，先运行 init 构建索引，然后在 Claude Code 中查询“列出所有 API 调用链”或“请求 Controller 到 Service 的完整路径”，快速理清架构，再开始安全重构。
