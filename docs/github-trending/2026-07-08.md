为技术型求职者（尤其丹麦市场）提供 CLI 驱动的求职流水线，可自动评估职位匹配度、适配 CV 并生成求职信。能力边界：本地运行依赖 Claude Code CLI、Python 和 LaTeX，门户搜索插件目前聚焦丹麦，需自行适配其他地区。

**不适合谁关注**
