**项目定位**

面向从事研究型编码、批量重构或需要长时间无人值守任务的开发与研究人员。它把提示词当作变量、子代理当作函数调用，在持久Python环境与Continual Harness中运行，使上下文、记忆、技能可持续累积，并可通过/refine基于证据小幅自我改进。能力边界：非安全沙盒，执行模型生成的代码需用户权限；自改进仅限本地harness状态，不修改基础系统提示词；当前支持macOS/Linux。

**为什么值得关注**

今日新增2293颗星，总星6471，star_today_ratio达35.44，属新项目爆发，是今日TOP3中绝对增量与相对热度最强者。0天前有提交，最新release v0.7.1于2026-08-07发布，迭代极快；近30天PR更新459、issue更新104，社区贡献活跃。README成熟（5,694字符，含安装说明、Demo与文档入口），但open issues 248，说明用户反馈多、边界仍在快速调整。其自改进RLM思路与论文/博客配套，适合追踪前沿代理架构。

**适合谁关注**

**不适合谁关注**

不适合对安全沙箱有硬性要求的生产环境，因代理以用户权限执行代码；不适合Windows用户；不适合期望零配置、纯图形化的新手；不适合需要稳定API、长期支持的企业关键业务。

**风险或争议点**

最大风险是代理会以用户权限执行模型生成的Python与shell命令，README明确不提供安全沙箱，需在隔离环境或外部沙箱中运行；自改进机制可能产生意外行为，需依赖快照回滚。项目仅发布至v0.7.1，接口与数据格式可能快速变化；需登录第三方API-key提供方，存在密钥管理与成本风险。组织采用前应做安全评估，限制网络与文件系统权限。

**最佳实践场景**

在Docker容器中启动一个用于代码库批量重构的长期任务：先克隆仓库到干净工作区，用prime-agent定义重构目标与约束，以自主模式运行，每小时检查日志，每天审查harness状态变化（/refine产生的更新）。设置定时快照，若出现越权文件操作立即回滚并缩小权限范围。复用/refine形成的技能加速下一次相似任务。
