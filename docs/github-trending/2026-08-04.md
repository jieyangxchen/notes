**不适合谁关注**

不适合需要直接识别扫描件内文字（OCR）的场景，因为库本身不做 OCR；不适合需要高精度复杂表格还原的金融文档场景（虽宣称支持，但 benchmark 有限）；不适合对 PDF 安全性要求极高的项目，解析不受信任 PDF 需谨慎。

**风险或争议点**

解析不受信任的 PDF 存在潜在安全风险，如恶意字体或畸形结构，应放在隔离沙箱运行；项目尚未发布正式 release，接口可能随版本迭代变化；性能数据基于 Apple M4 Pro 等特定硬件，需在目标环境自行基准测试；提取复杂版式（如多栏、嵌套表格）时可能失真，金融或合同文档仍需人工复核。

**最佳实践场景**

在 RAG 预处理阶段，用 pdf-inspector 快速分类，将扫描件送入 OCR 服务，文本型直接转 Markdown 入库，显著降低处理时间与成本；可将 WASM 集成到前端，实现浏览器端即时判断与分流。

- 评估：分类准确率≥95%，文本 PDF 单文档处理<200ms，输出 Markdown 可读性达内部标准。
- 退出：若准确率不达标或 API 变动频繁，则回退现有方案；否则集成到主处理管道并做回归测试。
