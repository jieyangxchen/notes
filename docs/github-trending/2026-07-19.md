**适合谁关注**

适合中大型代码库（如 monorepo）且频繁使用 AI 代码审查或重构的团队；注重隐私，所有分析本地运行；支持 30+ 语言，可结合 GitHub Action 集成 CI。

**不适合谁关注**

**最佳实践场景**

在 500+ 文件的 Python monorepo 中，安装 code-review-graph 后向 Claude Code 发起代码审查请求，观察其仅读取变更文件及相关调用链，验证审查速度与全面性提升。

**我会怎么试用它**

- 安装：pip install code-review-graph 或通过 uv 安装，然后对 Git 仓库运行 crg install。
- 试跑：选择一个 >200 文件的中型 Python 项目，执行 crg analyze 生成图谱，然后在 AI 助手内请求一次代码审查。
- 评估：对比使用前后 AI 助手读取的文件数量、token 消耗以及审查发现的真实问题数，要求文件数减少 >70%。
- 退出：若连续三次代码审查任务中上下文减少不明显或 AI 遗漏关键 bug，则回归传统方式；若项目变更为小型库则移除。
