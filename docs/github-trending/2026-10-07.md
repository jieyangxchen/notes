**适合谁关注**

**不适合谁关注**

**风险或争议点**

**最佳实践场景**

- 评估：看首次通过率、回放中无需模型的步骤占比、页面改版后的重录频率，以及模型调用成本与匿名遥测的合规性。
- 退出：若回放频繁失效、agent 步骤无法被断言稳定校验，或合规不允许调用外部模型，则回到原生 Playwright 手写用例。
