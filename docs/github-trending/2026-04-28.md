## 1. mattpocock/skills

**项目定位**

面向真实工程流程的 Agent Skills 集合。它把 PRD 生成、Issue 拆分、TDD、架构讨论、预提交保护、文章编辑等高频工程动作，整理成可安装、可复用的技能目录。

**为什么值得关注**

它连续两天冲到榜首，说明开发者正在把 AI 编码从“临场提示词”推进到“标准化流程资产”。这类技能库的价值不只是节省提示词编写时间，而是让需求澄清、任务拆分、测试驱动和提交保护这些关键动作在团队内更容易复制。

**最佳实践场景**

团队可以把它作为内部 AI 编码规范的参考模板：先挑选 PRD、Issue 拆分、TDD、Git guardrail 等少数技能试点，再按本团队的代码评审、测试和发布规则改写成私有技能库，避免每个成员各自维护一套不可追踪的提示词。

## 2. Alishahryar1/free-claude-code

**项目定位**

Claude Code 的 Anthropic API 兼容代理。它把 Claude Code CLI、VSCode 扩展或聊天机器人入口的请求，路由到 NVIDIA NIM、OpenRouter、DeepSeek、LM Studio、llama.cpp、Ollama 等云端或本地模型后端。

**为什么值得关注**

AI 编码工具正在出现“前端体验”和“模型供应”解耦的趋势。这个项目受关注，核心原因是它把熟悉的 Claude Code 使用方式保留下来，同时给成本控制、本地模型实验、多模型路由和额度管理留下空间。

**最佳实践场景**

个人或小团队可以用它搭建一套模型路由实验环境：轻量重构、文档生成走本地 Ollama 或 LM Studio，复杂推理走云端模型，并通过统一代理记录延迟、失败率和任务完成质量。正式用于生产代码前，应先审查密钥处理、请求日志、依赖可信度和各模型服务条款。

## 3. Z4nzu/hackingtool

**项目定位**

安全研究与渗透测试工具聚合器。项目以菜单方式组织 185+ 工具，覆盖信息收集、Web 安全、取证、逆向、云安全、移动安全、Active Directory 等类别，并提供搜索、标签过滤、推荐和安装状态管理。

**为什么值得关注**

安全工具链通常分散、安装和选型成本高。这个项目的热度来自“工具入口统一化”：它不解决单个漏洞检测问题，而是帮助安全学习者和安全团队快速看到工具生态的分类、覆盖面和实验环境组织方式。

**最佳实践场景**

企业安全团队可以在隔离、授权的靶场或培训环境中，用它做工具盘点和课程准备：先按信息收集、Web 检测、取证、云安全等类别建立工具地图，再筛选少量经过内部验证的工具纳入标准作业流程。

> 注意：安全类项目只适合授权测试、教学和防御研究，不应用于未授权目标。
