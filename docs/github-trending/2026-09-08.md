**我会怎么试用它**

- 评估：人工检查标题/链接/表格保留率大于 95%，表格错乱率低于 10%，单页耗时低于 2 秒；关键数据抽样与源文件比对无遗漏。
- 退出：多次发生表格数值或文本丢失、输入净化不足导致风险告警时，切换专用转换器并增加人工抽检环节。
