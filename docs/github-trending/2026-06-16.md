**最佳实践场景**

**我会怎么试用它**

- 安装：执行 `pip install skillspector` 或使用 `docker build -t skillspector .` 构建容器环境，依赖清晰。
- 试跑：选取 5 个已知安全的 AI 技能仓库和 3 个已知含漏洞的样本，运行静态扫描并生成报告，观察检出与误报情况。
- 评估：计算召回率（检出真实漏洞数/总真实漏洞数）、精确率（正确检出中真实漏洞的比例）、扫描平均耗时（期望 <3分钟）。
- 退出：若精确率低于 50% 导致过多人工复核，或扫描耗时超过 5 分钟/仓库，应暂停自动化集成，调整为仅手动触发深度扫描。
