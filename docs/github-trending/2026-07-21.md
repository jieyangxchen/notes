**适合谁关注**

**不适合谁关注**

**我会怎么试用它**

- 试跑：选择 >200 文件的中型 Python 项目，执行 crg analyze 构建图谱，在 Claude Code 中请求一次代码审查，记录 AI 加载的文件列表与 token 用量。

- 退出：若连续三次上下文减少不明显或 AI 遗漏重大缺陷，则回退传统 review 流程；项目规模缩减至微型库时移除工具。

**不适合谁关注**

**最佳实践场景**

在 Claude Code 中将 OmniRoute 设为 API 端点，为日常编码使用免费模型并启用压缩，对比一个月后可节省数百美元 token 费用。

**我会怎么试用它**

- 试跑：在 Claude Code 内执行一组典型编码任务，观察模型自动切换与压缩效果，监控延迟和成功率。
- 评估：统计一周 Token 用量和成本，对比直接付费 API，目标节省 >50%；确保核心任务（代码补全、解释）质量无明显下降，可用性 >99%。
- 退出：若免费额度频繁耗尽导致服务不可用，或压缩后模型输出不可接受，则回退至官方 API；若项目停更则迁移至其他聚合器如 LiteLLM。
